# Fintech Full-Stack Starter

Modern banking-style starter built with:
- Next.js
- Tailwind CSS
- Supabase

Features:
- Login / Signup
- Dashboard
- Account balance
- Transaction history
- KYC upload
- Admin panel
- Notifications

## Setup

1. Create a Supabase project
2. Copy `.env.example` to `.env.local`
3. Add your Supabase keys
4. Run:

```bash
npm install
npm run dev
```

## Deploy
- Push to GitHub
- Deploy on Vercel
